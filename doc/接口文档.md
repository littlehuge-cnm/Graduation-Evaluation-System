## 1 通用约定

### 1.1 请求头

| 头部字段 | 是否必填 | 说明 |
| --- | --- | --- |
| Content-Type | 是 | `application/json`（文件上传除外） |
| Authorization | 是（登录除外） | `Bearer <JWT Token>` |

### 1.2 统一响应结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

| 字段 | 说明 |
| --- | --- |
| code | 状态码，200 成功，401 未认证，403 无权限，400 参数错误，500 服务器错误 |
| message | 提示信息 |
| data | 业务数据，无数据时为 null |

### 1.3 角色权限说明

| 角色 | 权限范围 |
| --- | --- |
| admin | 超级管理员，拥有全部权限 |
| teacher | 教师，按身份上下文（指导/评阅/组长/秘书）过滤数据 |
| student | 学生，仅能查看本人信息 |

### 1.4 分页参数约定

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| pageNum | int | 1 | 页码 |
| pageSize | int | 10 | 每页条数 |

分页响应结构：

```json
{
  "code": 200,
  "data": {
    "total": 100,
    "pageNum": 1,
    "pageSize": 10,
    "list": []
  }
}
```

## 2 认证模块

### 2.1 用户登录

**请求**

```
POST /api/auth/login
```

**请求体**

```json
{
  "userType": "admin",
  "username": "admin",
  "password": "admin123"
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| userType | string | 是 | 用户类型：admin/teacher/student |
| username | string | 是 | 账号（管理员账号/工号/学号） |
| password | string | 是 | 密码 |

**响应**

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "userType": "admin",
    "username": "admin",
    "name": "系统管理员"
  }
}
```

### 2.2 用户退出

```
POST /api/auth/logout
```

**响应**

```json
{ "code": 200, "message": "退出成功" }
```

### 2.3 获取当前登录用户信息

```
GET /api/auth/info
```

**响应**

```json
{
  "code": 200,
  "data": {
    "userType": "teacher",
    "username": "T2026001",
    "name": "张老师",
    "identities": ["指导教师", "组长"]
  }
}
```

### 2.4 修改密码

```
PUT /api/auth/password
```

**请求体**

```json
{
  "oldPassword": "old123",
  "newPassword": "new123"
}
```

### 2.5 重置用户密码（超管）

```
PUT /api/auth/password/reset
```

**请求体**

```json
{
  "userType": "teacher",
  "username": "T2026001",
  "newPassword": "123456"
}
```

## 6 文档管理（任务书/指导书）

### 6.1 保存/更新文档（指导教师）

指导教师填写自己指导学生的任务书或指导书，支持草稿保存。

```
POST /api/documents
```

**请求体**

```json
{
  "studentNo": "2026001",
  "docType": "任务书",
  "title": "基于Spring Boot的毕业设计评价系统",
  "subjectCategory": "A",
  "subjectType": "A",
  "subjectNewOld": "A",
  "content": "课题研究主要内容与基本要求...",
  "status": "草稿"
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| docType | string | 是 | 文档类型：任务书/指导书 |
| title | string | 任务书必填 | 题目 |
| subjectCategory | string | 任务书选填 | 课题类别 A/B/C/D |
| subjectType | string | 任务书选填 | 课题类型 A/B/C |
| subjectNewOld | string | 任务书选填 | 新旧课题 A/B |
| content | string | 否 | 正文内容 |
| status | string | 是 | 草稿/已提交 |

### 6.2 修改文档（指导教师）

```
PUT /api/documents/{id}
```

### 6.3 提交文档（指导教师）

将文档状态从"草稿"改为"已提交"，学生方可查看。

```
PUT /api/documents/{id}/submit
```

### 6.4 查询文档详情

```
GET /api/documents/{id}
```

权限说明：指导教师仅能查自己学生的；学生仅能查自己的；超管可查全部。

### 6.5 按学生查询文档列表

```
GET /api/students/{studentNo}/documents?docType=任务书
```

### 6.6 查询指导教师待填写文档列表

```
GET /api/documents/my-students?docType=任务书
```

返回当前登录教师所指导学生的文档填写情况。

## 7 评价记录管理

### 7.1 录入开题成绩（组长）

```
POST /api/score-records
```

**请求体**

```json
{
  "studentNo": "2026001",
  "itemType": "开题成绩",
  "subScores": "4,3,4",
  "comment": ""
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| itemType | string | 是 | 条目类型（见 7.9 条目类型表） |
| subScores | string | 否 | 分项成绩，逗号分隔 |
| score | number | 否 | 总成绩（若未传则后端按分项求和） |
| grade | string | 否 | 等级（仅委员会评定填写） |
| comment | string | 否 | 评语/记录内容 |

权限说明：根据 itemType 自动校验当前用户身份是否匹配录入角色。

### 7.2 修改评价记录

```
PUT /api/score-records/{id}
```

权限：仅原录入人或超管可修改，需环节处于"进行中"。

### 7.3 查询评价记录详情

```
GET /api/score-records/{id}
```

### 7.4 按学生查询全部评价记录

```
GET /api/students/{studentNo}/score-records
```

**响应**

```json
{
  "code": 200,
  "data": [
    { "itemType": "开题成绩", "score": 11, "recorderName": "张老师" },
    { "itemType": "外文翻译", "score": 3, "recorderName": "李老师" }
  ]
}
```

### 7.5 按学生+条目类型查询

```
GET /api/students/{studentNo}/score-records?itemType=开题成绩
```

### 7.6 查询待录入列表（按角色）

返回当前登录教师需要录入的成绩列表。

```
GET /api/score-records/todo
```

例如组长调用返回本组学生的开题成绩/中期检查/答辩成绩待录入项；指导教师调用返回自己学生的外文翻译/指导评语待录入项；秘书调用返回本组答辩记录待录入项。

### 7.7 录入外文翻译成绩（指导教师）

```
POST /api/score-records
```

```json
{
  "studentNo": "2026001",
  "itemType": "外文翻译",
  "subScores": "1,1,1"
}
```

### 7.8 录入中期检查（组长）

```
POST /api/score-records
```

```json
{
  "studentNo": "2026001",
  "itemType": "中期检查",
  "subScores": "5,4,5",
  "comment": "进度正常，已完成主要模块设计。"
}
```

### 7.9 条目类型表

| itemType | 录入人 | 分项满分 | 总满分 |
| --- | --- | --- | --- |
| 开题成绩 | 组长 | 4+4+4 | 12 |
| 外文翻译 | 指导教师 | 1+1+1 | 3 |
| 中期检查 | 组长 | 5+5+5 | 15 |
| 指导评语 | 指导教师 | 3+3+3+3+3 | 15 |
| 评阅评语 | 评阅教师 | 4+4+4+3 | 15 |
| 答辩记录 | 秘书 | 无分项 | — |
| 答辩成绩 | 组长 | 10+10+10+10 | 40 |
| 委员会评定 | 超级管理员 | 加权总分 | 100 |

## 8 环节状态管理

### 8.1 查询学生环节状态

```
GET /api/students/{studentNo}/stage-status
```

**响应**

```json
{
  "code": 200,
  "data": [
    { "stage": "开题", "status": "已完成", "startTime": "2026-03-01 09:00:00", "completeTime": "2026-03-10 17:00:00" },
    { "stage": "中期", "status": "进行中", "startTime": "2026-04-10 09:00:00", "completeTime": null },
    { "stage": "答辩", "status": "未开始", "startTime": null, "completeTime": null }
  ]
}
```

### 8.2 启动环节（超管）

将指定环节状态从"未开始"置为"进行中"，前置环节必须为"已完成"。

```
PUT /api/stage-status/start
```

**请求体**

```json
{
  "studentNo": "2026001",
  "stage": "中期"
}
```

### 8.3 完成环节（超管/组长）

将指定环节状态从"进行中"置为"已完成"。

```
PUT /api/stage-status/complete
```

**请求体**

```json
{
  "studentNo": "2026001",
  "stage": "中期"
}
```

### 8.4 批量启动环节（超管）

按学生组批量启动某环节。

```
PUT /api/stage-status/start-batch
```

**请求体**

```json
{
  "stage": "开题",
  "studentGroupId": 1
}
```

### 8.5 查询环节进度总览（超管）

```
GET /api/stage-status/overview?stage=开题&groupId=1
```

```
GET /api/manual-export?studentNo=2026001
```

**响应**：返回 Word 文件流，文件名为"学生姓名.docx"。

```
Content-Type: application/vnd.openxmlformats-officedocument.wordprocessingml.document

```

权限：指导教师仅能导出自己学生；学生仅能导出本人；超管可导出任意学生。

```
POST /api/manual-export/batch
```

**请求体**

```json
}
```

**响应**：返回 ZIP 压缩包，包含多个"学生姓名.docx"。

### 9.3 按学生组批量导出（超管）

```
POST /api/manual-export/by-group
```

**请求体**

```json
}
```

## 10 操作日志

### 10.1 分页查询操作日志（超管）

```
GET /api/operation-logs?pageNum=1&pageSize=20&userType=teacher&startTime=2026-03-01&endTime=2026-06-30
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| userType | string | 否 | 用户类型过滤 |
| userNo | string | 否 | 用户账号过滤 |
| startTime | string | 否 | 起始时间（yyyy-MM-dd） |
| endTime | string | 否 | 截止时间（yyyy-MM-dd） |

**响应**

```json
{
  "code": 200,
  "data": {
    "total": 100,
    "pageNum": 1,
    "pageSize": 20,
    "list": [
      {
        "id": 1,
        "userType": "teacher",
        "userNo": "T2026001",
        "operation": "录入开题成绩 学生：2026001",
        "operationTime": "2026-03-05 10:30:00",
        "ip": "192.168.1.100"
      }
    ]
  }
}
```
